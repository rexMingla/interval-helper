# interval-helper
Garmin Connect IQ app (Monkey C) for interval based activity recording.

Available on the Garmin Connect IQ Store: [Interval Activity Recorder](https://apps.garmin.com/apps/8c70ee26-f598-42c5-8a76-3838cae0f96e)

## Using it
- **START/STOP** opens the start menu (start, select activity, select recording mode). While recording it pauses and
  opens the pause menu (resume, save, discard).
- **BACK** starts the next lap. Laps alternate between on and off (recovery) laps. Before the activity has started it
  exits the app.
- **UP/DOWN** switches between the current lap and total views.
- Activities: run, bike, swim, other.
- Recording mode controls what happens on off laps: ignore them, record without GPS, or record with GPS.

## Requirements
- Connect IQ 3.0.0 or later. Built with Connect IQ SDK 9.3.0.
- The supported devices are listed in `manifest.xml`. That file is generated by the Monkey C extension, so add or
  remove devices through the extension rather than editing it by hand.

## Building
Open the folder in VS Code with the Monkey C extension. `.vscode/settings.json` sets the type check level to Strict,
and the code compiles cleanly at that level. To build one device from the command line:

```
monkeyc -f monkey.jungle -d fenix843mm -l 3 -w -o bin/interval-helper.prg -y <developer_key>
```
